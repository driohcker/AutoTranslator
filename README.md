# AutoOCRTranslator

实时屏幕文字识别与翻译工具。截取游戏画面指定区域，自动 OCR 识别原文并调用翻译服务，将译文叠加显示在屏幕上方，帮助玩家阅读外语游戏内容。支持多套翻译缓存方案快速切换，适配不同游戏。

## 功能特性

- **截图识别**：两种捕获模式
  - 目标窗口：截取相对于选中窗口的固定区域，窗口移动时区域跟随
  - 全屏模式：截取虚拟屏幕上的任意区域，跨多显示器可选
- **OCR 识别**：基于 RapidOCR，支持日语、英语、简繁中文等语言识别，并提供语言过滤与置信度过滤
- **多翻译服务**：阿里云、腾讯云、DeepL、Google 免费接口，凭据按服务动态显示
- **翻译缓存**：SQLite 本地缓存，支持多方案管理——为每个游戏建立独立方案，切换游戏时一键切换活动方案，无需清空重导
- **覆盖层显示**：译文以悬浮窗口叠加在屏幕原图位置，全屏模式下使用 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` 排除自身捕获，避免自反射震荡
- **区域选择器**：多显示器全屏覆盖选区，目标窗口边界以蓝色虚线标注，拖拽预览超出目标窗口时显示虚线提示
- **托盘驻留**：最小化到系统托盘，后台持续运行

## 项目结构

```
AutoTranslator_win/
├── config/settings.yaml          # 运行配置（翻译服务凭据、OCR、缓存、覆盖层）
├── src/AutoOCRTranslator/
│   ├── Cache/                    # 翻译缓存（SQLite，多方案）
│   ├── Capture/                  # 截图循环、变更检测、窗口/全屏捕获
│   ├── Gui/                      # 主窗口、各功能页、区域选择器、捕获会话
│   ├── Ocr/                      # OCR 引擎封装、语言过滤、识别流程
│   ├── Overlay/                  # 译文覆盖层窗口
│   ├── Settings/                 # 配置模型、加载/保存、UI 预设
│   ├── Translate/                # 翻译服务实现（阿里云/腾讯/DeepL/Google）
│   └── Utils/                    # 工具（路径、图像、日志、托盘、窗口枚举）
├── tests/AutoOCRTranslator.Tests/  # 单元测试（缓存/检测/过滤/管线）

```

## 构建与运行

依赖 .NET 10 SDK。模型文件体积较大不随仓库分发，需自行放入 `models/` 目录后构建运行。

```powershell
# 构建
dotnet build src/AutoOCRTranslator/AutoOCRTranslator.csproj

# 开发运行（便捷脚本）
.\dev_run.cmd
# 或
.\scripts\dev_run.ps1

# 运行测试
dotnet test
```

## 配置

运行配置位于 `config/settings.yaml`，包含：

- **应用**：版本号
- **截图**：捕获模式（TargetWindow / FullScreen）、目标窗口、识别区域、刷新频率、变更检测阈值
- **OCR**：引擎参数、语言、过滤、置信度
- **翻译**：服务类型、源/目标语言、方向预设、凭据（按服务）
- **缓存**：启用开关、数据库路径、过期天数、活动方案
- **覆盖层**：字体、背景、边距、位置微调

UI 设置页修改后会自动写回该文件。

## 使用流程

1. 在设置页选择截图模式（目标窗口需先选中目标游戏窗口；全屏模式可在任意位置框选区域）
2. 在缓存页新建翻译方案并切换为活动方案
3. 配置翻译服务凭据并测试连通
4. 启动捕获，覆盖层会自动显示译文
5. 切换游戏时切换缓存方案即可复用历史译文
